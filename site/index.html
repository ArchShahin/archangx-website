01 · What we do

ML Wildfire Detection

Autonomous wildfire detection that runs on board: a physics-informed hybrid model scores thermal anomalies where the imagery is captured, so a fire becomes a geolocated event instead of a raw download.

Multi-modal Earth observation→Onboard thermal scoring→ Geolocated fire events→Tasking and emergency logistics

Physics-informed scoring

Thermal physics and machine learning combined, so detections stay explainable and robust to clouds, sun glint and hot surfaces.

Processing in orbit

Anomalies are scored on board and in the orbital data centre, cutting the delay between first heat signature and alert.

From pixel to response

Each detection is a geolocated event that can retask satellites and feed emergency logistics in near real time.
