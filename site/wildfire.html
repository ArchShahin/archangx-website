Seraphim Guardian · Wildfire intelligence

Guardian Uriel: intelligence that sees the first spark

Celestial Intelligence Protecting Life on Earth. Earth-observation constellations capture far more than can be sent to the ground. Guardian Uriel detects wildfire ignitions where the data is captured, so what comes down is a geolocated, signed alert in minutes, not a raw image hours later.

The detection pipeline

From photon to response

Eight stages, from the sensor to the people who act. The first five run on board the satellite or in the orbital data centre.

Satellite thermal and multispectral sensors→Radiometric calibration and quality masking→ Physics-based thermal candidate detection→Compact onboard AI verification→ Confidence and uncertainty scoring→Geolocated event generation→ Secure priority alert delivery→Ground dashboard and event archive
Detect

Physics-informed detection

Thermal physics finds the candidates and a compact model verifies them, which keeps detections explainable and robust to clouds, sun glint and naturally hot surfaces. If the model is unavailable or untrusted, the physics-only path still produces events.

Compute

Onboard and orbital processing

Detection runs on the satellite's edge computer and in the orbital data centre, cutting the time between the first heat signature and an alert on the ground.

Report

Geolocated events with confidence

The output is a fire event with a location, a confidence and an uncertainty, signed at the source: ready to retask satellites and to reach the people who respond.

Respond

Built for emergency management

Designed around real emergency workflows: priority alert delivery, a ground dashboard, an event archive, and integration with the agencies that act on an alert.

Data and features

What Uriel works with

The pipeline is designed for the thermal bands that see fire, with optional context bands and explicit quality flags, so that every event states how much it can be trusted.

  • Mid-wave and long-wave infrared (MWIR and LWIR) thermal data
  • Optional short-wave infrared (SWIR) and visible context
  • Cloud and sensor-quality flags carried with every event
  • Physics-only fallback when the AI model cannot be used
  • Temporal correlation of repeat detections of the same fire
  • Fire Radiative Power estimation
  • Signed event provenance from the satellite to the archive
  • Synthetic demonstration mode, always marked as synthetic

Why in orbit

Less data down, faster answers

Downlink capacity, not sensors, limits how fast a fire is seen. Processing at the edge sends the answer first and the evidence after.

  • Detection where the imagery is captured
  • Only events and evidence are downlinked
  • Heat signatures confirmed with thermal physics, not only patterns
  • Each event can trigger more observation of the same area
The name

Named after Uriel

Uriel is the archangel of light, wisdom and fire. The name states the intent: to see, to understand and to warn. The seeing itself is thermal physics, verified by a compact model and signed before it leaves the satellite.
